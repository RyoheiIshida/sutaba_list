# 店舗検索へのマップ機能追加実装計画

## Context
店舗一覧ページにマップ検索機能を追加し、ユーザーが店舗を地理的に確認できるようにする。現在はリスト表示のみで、Google Maps APIとStoreMapコンポーネントは既に利用可能。ユーザーはより便利な店舗検索機能を求めており、地図上での店舗確認と現在地からの近さ順検索を希望している。

## 要件
- **表示方式：** 切り替えボタンでマップビューとリストビューを切り替え
- **初期表示：** マップビューから開始
- **位置情報機能：** 現在地取得と近さ順ソートを追加
- **連携機能：** マップとリストの選択状態を同期
- **既存機能：** フィルタリング機能とマップ表示を連携

## 技術的詳細

### レスポンシブレイアウト
- マップ表示時：幅100%、高さはレスポンシブ（モバイル500px、デスクトップ600px）
- リスト表示時：既存のグリッドレイアウト維持
- 切り替えボタン：固定位置で常に表示

### 距離計算ロジック
```typescript
function calculateDistance(lat1: number, lon1: number, lat2: number, lon2: number): number {
  const R = 6371; // 地球の半径（km）
  const dLat = (lat2 - lat1) * Math.PI / 180;
  const dLon = (lon2 - lon1) * Math.PI / 180;
  const a = Math.sin(dLat/2) * Math.sin(dLat/2) +
            Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) *
            Math.sin(dLon/2) * Math.sin(dLon/2);
  const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
  return R * c;
}
```

### 状態管理

## 検証方法

### 機能テスト
1. **ビュー切り替え：** マップとリストの切り替えが正常に動作する
2. **マーカー表示：** すべての店舗がマップ上に正しく表示される
3. **マーカーインタラクション：** マーカークリックでインフォウィンドウが表示される
4. **リスト連携：** マーカークリックで対応するカードがハイライトされる
5. **フィルタリング：** フィルター変更でマップとリストの両方が更新される
6. **位置情報：** 現在地ボタンで現在位置が取得できる
7. **距離ソート：** 「現在地から近い順」で正しくソートされる
8. **レスポンシブ：** モバイルとデスクトップで適切に表示される

### エラーテスト
1. **APIキー未設定：** 適切なエラーメッセージが表示される
2. **位置情報拒否：** エラーハンドリングが動作する
3. **店舗データなし：** 空の状態が適切に表示される
4. **ネットワークエラー：** エラーメッセージが表示される

### パフォーマンステスト
1. **多数の店舗：** 多数のマーカー表示でもパフォーマンスが良好
2. **ビュー切り替え：** 切り替えがスムーズでラグがない
3. **地図読み込み：** マップが適切な時間で読み込まれる

- **初期表示：** マップビューから開始し、直感的に店舗位置を確認可能
- **切り替えボタン：** 明確なアイコンで直感的な操作
- **現在地ボタン：** ワンクリックで現在地を取得
- **選択フィードバック：** 選択した店舗が視覚的に強調
